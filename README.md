# Consumer APP

O App foi feito utilizando a plataforma Android.
Em seguida está o passo a passo para rodar o projeto.

## 1: Clonar o projeto na sua máquina
```bash
git clone https://github.com/yurisamagaia/consumer-app.git
```

## 2: Instalar as dependências 
```bash
yarn install
```

## 3: Iniciar o Metro
```bash
yarn start
```

## 4: Iniciar a aplicação
```bash
yarn android
```

## 5: Rodar os testes
```bash
yarn test
```

# Sobre o projeto

Ferramentas utilizadas no desenvolvimentoL

- [React Native](https://reactnative.dev) - Utilizado a última vesão estável (0.76.6) com melhorias de desempenho, novos recursos e suporte a bibliotecas modernas.
- [Jest](https://jestjs.io/pt-BR/) - Foram utilizados testes com Jest, para manter a integridade das funcionalidades.
- [TypeScript](https://www.typescriptlang.org/) - Tipagem estática, redução de erros em tempo de execução e melhor suporte do editor.
- [Styled Components](https://styled-components.com/) - Estilização no próprio componente, com suporte a temas dinâmicos e código mais legível.
- [Context API](https://react.dev/reference/react/useContext) - Gerenciamento de estado simples e eficiente sem a necessidade de bibliotecas externas.
- [FlatList](https://reactnative.dev/docs/flatlist) - Gerenciador de listas eficiente focado em performance.
